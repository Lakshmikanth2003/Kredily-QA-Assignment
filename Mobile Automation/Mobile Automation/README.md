# Mobile Automation

Automated 5 important Kredily HRMS mobile user journeys using Appium, UiAutomator2 and WebdriverIO.

## Automated Journeys

1. Login / Session Validation
2. Clock Out
3. Attendance / Home Validation
4. Leave & Leave Balances
5. Expense Workflow

See the JavaScript files and Automation Execution Report in this folder.
